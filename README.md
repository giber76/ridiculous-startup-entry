Entry for the make.fun bounty [Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

`main.ts` writes one sentence (max 200 characters) to `/output/entry.txt`,
pitching a startup idea so strange it sounds like a joke — yet specific enough
that a reader can see the customers and the money.

Run locally:

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
